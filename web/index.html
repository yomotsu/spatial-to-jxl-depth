HEIC を選ぶと元画像のサイズが入ります。

Distance は色画像の「見た目の差」を指定する画質設定です。数値が低いほど元画像に近く、高いほど見た目の差を許容します。
数値を上げると容量は小さくなる傾向がありますが、その分劣化します。
0 はロスレス、1 は視覚的にほぼロスレスの目安です。よく使われる非可逆圧縮の範囲は 0.5〜3.0、指定可能範囲は 0〜25 です。
チャンネルごとに異なる Distance を指定できますが、このアプリでは深度チャンネルにも色チャンネルと同じ Distance が適用されます。
なお、libjxl の cjxl では Quality（0〜100）も指定できますが、内部で Distance に変換されます。
